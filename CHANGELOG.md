# Changelog

All notable changes to GitHub Deco are recorded here.

The project follows [Semantic Versioning](https://semver.org/). Release entries
are finalized through a pull request before the matching `vX.Y.Z` GitHub
Release is published.

## Unreleased

### Added

- Public contribution, governance, security, and release documentation.
- Structured issue forms, a pull request template, and code ownership routing.
- Continuous integration, dependency review, CodeQL, and Dependabot
  configuration.

### Changed

- Repository links and package metadata now point to
  `laigit-dot/profile-shop`.
- The supported runtime baseline is Node.js 22.12 or newer, with Node.js 24
  used for primary development and continuous integration.
